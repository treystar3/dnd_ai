# Blind pairs from a played game: two writers, the same typed lines

Two writers each ran the whole game from the same start (the same seed, character and companions), and the same lines were typed
to both, in this order. For each typed line, A and B are everything the game showed the player in each run: plain text is the
narrator, a bold name is someone speaking, a line in italics is the game's own notice. Which run is A and which is B was decided
by a coin for every pair. The two runs' worlds differ in small ways (who was met, what was found, where a line led), so A and B
need not agree with each other: judge each as what a player would read after typing that line.

For each pair, four answers:

1. **better**: which would you rather have read as the player: A, B, or same.
2. **machine**: any that reads as written by a machine and not by an author: A, B, both or none.
3. **padded**: any that says far more than the moment needs, or decorates instead of telling.
4. **ignores**: any that does not do or answer what was typed.
