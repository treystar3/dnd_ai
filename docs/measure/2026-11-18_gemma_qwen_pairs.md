# Blind pairs: two writers, the same moments

Each pair below is one moment in the game and two replies to it, by two different writers. Which writer is A and which is B was
decided by a coin for every pair, so the letters carry nothing from one pair to the next. Both writers were sent exactly the same
request. "Who answers" and "The moment" are true in the game; the writers were told them (unless a line says otherwise).

For each pair, four answers:

1. **better**: which reply would you rather the game had said: A, B, or same.
2. **machine**: any reply that reads as written by a machine and not by a person of that world: A, B, both or none.
3. **untrue**: any reply that contradicts the moment, or makes up a named person, a place, a price or an event the moment does not hold.
4. **character**: any reply that does not fit who answers (their personality, traits, manner, how they talk).

Answer in the chat however is easiest, for example `12 A` or `12 B, machine A, untrue A`. The first answer alone is enough. The key is in a separate file; nothing here says which writer is which.
