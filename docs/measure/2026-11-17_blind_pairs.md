# 20 pairs of replies, to be read blind

Each pair is two replies to the same typed line by the same speaker, from two runs of the same script on the local model.
One run had the speech as it is today, the other the speech of phase 4 (decide, then speak). Which is A and which is B changes
from pair to pair and is written down elsewhere. The talk before each line is not the same in the two runs, so a reply may
pick up something the other does not.

For each pair: which reply would you rather the game had said (A, B, or no preference), and does either read as written by a
machine rather than said by a person?
