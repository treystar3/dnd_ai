# gate: Checks on what the model wrote

This workstream stops the game asking the model twice for an answer that needed no second call, and stops its checks refusing ordinary words. In the 44 tracked runs 556 answers were sent back and 41 requests lost; about 300 of the 556 are faults with one certain mend (an underscore join, a carriage return, a sentence of a frame), and about 60 more are false alarms of a check. It builds seven pieces of infrastructure: one mend pass before the gate; one whole-word matcher for every word list a check reads; one reader of amounts and game words that takes "given" from the request that was sent; one set of speech checks every speaker passes on every pass; one reader for coined names; a retry that asks again only for the entries that failed; and a retry that names every fault of a draft and forgets none named before. It also closes single faults in the same system (a checked draft thrown away, a journal note lost, a gesture never checked, a reason that changes with the hash seed). Left to the owner: whether the send-back order chosen for the output gate may change for the exact mends; the content guard's lists; what counts as an amount in party talk; whether the checked stock phrases are all shown; and whether a grammar rule against other scripts is built after its measure.

### GATE-1. A fault with one certain mend is mended before the gate, counted, and never costs a second call
- Fixes: logs-sendbacks-3, logs-sendbacks-11, logs-sendbacks-4, llm-flow-7, llm-hot-6, llm-checks-2, llm-checks-13, logs-sendbacks-9
- Pillar: 5 Writing a reader wants to keep reading (no machinery in the story), and infrastructure (the 60 second turn); checklist 4, 5, 7
- Kind of case: Any fault in the prose or speech of a model's answer that has exactly one reading and that the engine can put right for certain (a carriage return, a line break written as backslash and n, a JSON tail at the very end, two words joined by an underscore that is no label of the request) is mended in place before any check runs; everything with more than one reading is still sent back.
- Build: engine/hygiene.py gains mend(text, request) and mend_answer(task, data, request). It walks the parsed answer by prose key, as prose_of does for a dict; undash_answer cannot be the walker, since it walks the fields of a validated model and this pass runs before there is one. llm/gateway.py _generate calls it for guarded tasks before schema validation: parse the raw text, mend the prose fields, write the mended answer back as JSON and validate that text with model_validate_json as today, so no contract is validated in another mode than it is now; raw text that does not parse goes to the validator untouched and fails as it does today, and an answer in which nothing was mended is validated from the raw text itself, never from a re-dump (a re-dump can differ from the raw in ways no mend asked for: a number written 1.0, a key written twice). The contracts' own speech checks and hygiene.problem() then both see the mended words; the model's own raw text is what stays in the call log, in the recording and in a retry. The rules, in order: CR LF is a line break and a lone CR a space (the rule clean() has at lines 184-185, lifted into one function both use); backslash-n is a line break; a brace or quote-and-brace is dropped only when nothing but space or closing punctuation follows; an underscore join is mended only when the token as written stands nowhere in the request, by shape: lower-case word, underscore, capital is a sentence end (name or not: all 8 logged word_Name cases were new sentences), Name_Name is a space only when the pair stands in the request, two lower-case words take the request's own hyphen form when it has one (else the hyphen-or-space rule the logged cases settle), a trailing underscore is dropped before punctuation or the end and is a full stop before a capital. Still sent back as today: a token that is in the request (a leaked id), a coded id, a trailing underscore before a lower-case word (about 25 logged, no single reading), JSON in mid-passage, a backspace. Each mend is counted by task and kind (a counter beside REPAIRS, declared in engine/owned.py STATE as owned_state_633_test.py asks of every module-level name written after import, and a field on the call's log row outside the request's hash) so a night's report says how often the model does it. data/rules/hygiene.yaml gets a `mend` table (each shape on or off, so a shape whose logged mends read wrong stays a send-back) and two reasons of its own for what is still sent back (words run together, which is not "the game's label"; a control character shown as a visible escape, not quoted raw); engine/hygiene.py problems() checks the table. Speech takes the same pass, which settles the 7 logged speaker underscores; a stock opener is deliberately not mended (cutting it breaks half of the logged hits; see GATE-9), and the quotation-mark and side-field mends of the first round wait until one is seen (0 in 1,340 replies).

Start from audit/work/logs_sendbacks/replay_gate.py, ids.py and broken.py, and llm_checks_verify.py.
