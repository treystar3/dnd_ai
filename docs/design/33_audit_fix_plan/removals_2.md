# removals_2: Dead code and unneeded files

This part places 41 findings: the entries of the removal list (docs/design/32_code_audit/removal_list.md) that fall in the model layer, the scenes, the shell, the tools and the documents, and the seven findings the list did not take (the bug in the import of old-layout saves, the check of a hire's opinions that can never report, the two mentor switches, the gzipped call logs of the kept recordings, and three on design documents that no longer say where the work stands). So that what is removed stays removed, it builds one census of what nothing reads for both parts of this workstream (REMOVALS_2-1: imports, names, helpers only tests call, files no file names, with OWED and KEPT tables); the other part's REMOVALS_1-1, REMOVALS_1-2 and REMOVALS_1-10 are written as its sweeps and say so, and REMOVALS_1-5 keeps its own fence for unread parameters. Beside the census this part builds: one reader for a recording's call log; a startup check that no call states a temperature the sampling table decides; a rule of the census that a contract counts as reached only when a call asks for it; a check that every declared name of the scene is read and can change; and a fence that every field of a small reader's answer is read. Six features here are the same change as a feature of the other part (the same removal-list entry reported by another finder), and a seventh (REMOVALS_2-10) shares names with three of them: each says so in its first words, and the pair is approved, built and numbered once. Left to the owner: whether the old-layout import is retired or mended, whether the model's motive step is retired, the two mentor switches, the form of the kept call logs, an old survey script and the root scripts, how the design folder marks finished documents, and two git commands only the owner should run.
