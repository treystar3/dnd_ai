# contracts: What the model is asked to write

This workstream closes the kinds the audit found in what a call asks the model to write: a field the engine already knows it will not keep, a side string with no end, an id the engine holds written back as a free string, a field the grammar lets be empty and the validator then refuses, and layout the grammar lets the model spend tokens on. It builds six pieces of infrastructure: a reply contract built for the call (the journal note only when one is due, the things shown as a closed list); a static declaration of an answer's shapes by its deciding field (`variants`), built first because a lost find is the one high fault here that needs no call context; one step that shapes any call's schema from what the call holds (`shaped`: `of`, `when`, `count`); one helper and one data file that give every string that is neither spoken nor narrated an end; a suite test that the smallest answer a grammar allows is never refused for being empty; and a replay measure (`tools/contract_ab.py`) that says per task whether a contract change helped, with a compact space rule as its first use. Nothing here adds a rule to a narrator or speaker prompt, and nothing bounds speech, gesture or narration. Almost every feature moves the schema fingerprint of some recorded request, so each says which recordings it moves and why that is meant. Left to the owner: what the pinned grammar test should guard, whether the compact space rule counts as a change to sampling, how wide the first pass of bounded strings is, who sets a creation perk's strength, whether a hire's secrets carry weights, what becomes of the impression line, and whether the road hazard keeps its own ruling call.
