# tools_bots: Tools that play or measure

This workstream mends the tools that play the game from outside (the balance bot, the night bot, the event bot) and the tools that read what a run left behind (latency, the reports, the yardsticks), so that a number one of them prints is a number it measured, and so that no tool can harm a player's game or another run's record. It builds seven pieces of infrastructure: one helper that is the only way a tool clears or removes a save; one run-start step that gives a measuring run a folder and logs of its own; one bench in simlib that puts back everything a tool replaced and opens with that step; one reader of the call log that says what a call, a first try and a token read are, with a call id the gateway writes; a waited-for-the-card figure on every call row; a speaker on every speech row; and a suite table that runs every hand tool under the stub. Around these are single-place mends, each with its own check: the balance bot's taps, the night and event bots' goals, the divergence yardstick, the pulse log's minute, the capped-list readers, the gate's exit code, the readers' file parser, think_ab's request. Nothing here changes what the narrator or a speaker is asked, nothing moves the data hash, and no feature needs a session on the card of its own. Left to the owner: what a tool does with a save already on disk that carries no marker, whether both bot reports stay, which hand switches of the bot stay, whether a recording keeps a per-call grammar for think_ab, and the reading of the night bot's reworded template lines.
